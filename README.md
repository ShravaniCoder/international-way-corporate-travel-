# International Way — Corporate Travel & Hospitality

React + Vite + Tailwind luxury corporate travel website.

## Structure
- `src/pages/` — one file per website page
- `src/components/` — reusable header, footer, hero, cards, CTA and UI components
- `src/data/siteData.js` — image URLs and page data
- `public/images/hero-airport.png` — the new homepage hero image
- `src/App.jsx` — routing only

## Pages
Home, About, Services, Corporate Solutions, Global Reach, Contact.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The hero image has been changed to the new airport visual. All other existing image URLs are preserved.
